# Support

## How to file issues and get help

This project uses [GitHub Issues](https://docs.github.com/issues) to track bugs
and feature requests. Please search the existing issues before filing new ones
to avoid duplicates. For new issues, file your bug or feature request as a new
issue.

For help and questions about using this project, please open a GitHub issue and
use the appropriate template (question / bug / feature request).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
